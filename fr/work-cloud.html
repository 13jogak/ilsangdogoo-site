Bol-nuage

구름그릇

J'ai passé un été entier à dessiner les nuages au-dessus du village où se trouve mon atelier, un dessin par jour. Je voulais garder un peu de cette abondance avant qu'elle ne passe.

Le soleil et la lune font nos journées, mais ce qui remplit les heures entre les deux n'a jamais deux fois la même forme. Un chaha (茶荷) pour les feuilles de thé sèches. Un bol de tous les jours. Un vide-poche pour les alliances des jeunes mariés. Il est taillé dans les feuillus de Corée et, comme les nuages, il n'y en a pas deux pareils.

Détails

Dimensions : env. 12,5 × 8 × 3 cm · Zelkova, cerisier, toona, maackia, entre autres · Finition : huile ou ottchil (urushi)

Chaque pièce étant sculptée à la main, les dimensions peuvent varier. Les légères différences de couleur et de forme sont le caractère propre de chaque bois.
